# App-Store-Assets (Quellen)

- Quelle Icons: `public/icons/` (`icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png`, `apple-touch-icon.png` 180) — Design: `packages/eh-design`, keine eigenen Entwuerfe.
- Kopien hier dienen als Arbeitsgrundlage fuer `@capacitor/assets`.
- FEHLT: 1024x1024-App-Icon (Apple-Pflicht) — auf dem Mac aus `icon-512.png`
  bzw. Logo-Vektor hochskalieren/feinzeichnen, dann `npx capacitor-assets generate`.
- Splash: Storyboard-Default aus `ios/`-Template; Marken-Splash (`--eh-*`) auf dem Mac ergaenzen.
